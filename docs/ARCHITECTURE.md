# Архитектура (план следующих этапов)
Loader.exe (WPF) → backend API (ASP.NET Core + PostgreSQL) → GitHub-реестр (пишет только backend) → HudLoader.asi → hud.asi.
Backend — источник истины по пользователям, лицензиям и отзыву; manifest подписывается серверным ключом,
клиент проверяет SHA-256 и подпись публичным ключом, offline grace period ограничен. Токены/пароли в клиенте не хранятся.
Ядро этого этапа (`src/`) портируется в Loader либо вызывается как отдельный процесс.
